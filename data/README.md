# 数据说明

## 这是什么

`data/` 中是 12 张**程序化渲染**的答题卡，不是实拍照片：

- 每张 1240×1754 px（A4，150 dpi），20 行 × A/B/C/D 四个选项；
- 每题恰好一个选项被铅笔涂黑；
- 共 12×20 = 240 个填涂区域，12×80 = 960 个选项气泡；
- 4 张清晰（clean）、4 张光照不均（light）、4 张低对比/噪声（hard）；
- 按组分层：6 张验证（2/2/2），6 张测试（2/2/2）。

## 目录

```text
data/
├─ images/S01.jpg ... S12.jpg   # 输入图
├─ masks/S01.png ... S12.png    # 像素级真值：被选中的选项内圆
├─ annotations/S01.json ...     # 每题答案、气泡坐标、填涂强度、随机种子
├─ index.csv                    # 图像 / 掩膜 / 标注 / 组别 / 划分
├─ splits.json                  # val / test
└─ dataset_stats.json           # 数量统计
```

## 生成方法

`src/make_dataset.py` 固定随机种子 `20261108`，用 Pillow 渲染：

1. 米色纸面 + 低频纸纹 + 细颗粒噪声；
2. 标题、考生信息、题号、四个空心气泡、评分区；
3. 每个答案在半径 14 px 内画半透明石墨底 + 5–8 条铅笔短线 + 颗粒；
4. 叠加光照梯度、随机阴影、暖色偏、暗角；
5. 高斯模糊、高斯噪声、JPEG 压缩；
6. 真值掩膜由填涂参数直接导出，不经过人工标注。

| 组别 | 光照/阴影 | 模糊半径 | 噪声 σ | JPEG 质量 | 铅笔强度 |
|---|---|---:|---:|---:|---|
| clean | 轻微梯度，无阴影 | 0.55 | 2.0 | 95 | 0.60–0.95 |
| light | 较强梯度 + 柔和阴影 | 1.00 | 4.0 | 91 | 0.38–0.82 |
| hard | 强梯度 + 强阴影 + 低频斑块 | 1.45 | 6.5 | 86 | 0.16–0.52 |

## 为什么用合成数据

- 课程设计只需要验证阈值/形态学流程，合成数据可以提供**精确到像素**的真值，不需要手工标注；
- 不涉及真实考生信息；
- 退化参数可复现，方便比较不同阈值策略。

## 局限

- 合成铅笔纹理比真实石墨规整，真实照片中的反光、纸纹、透视、折痕更复杂；
- 所有图像已经裁切对齐到固定版式，**不含旋转/透视**；
- 因此测试集上的 100% 不能直接外推到真实手机照片。报告第 3.4 节和第 5.5 节对这一点有说明。
